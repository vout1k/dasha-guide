Раздел 02
Твоя роль: Операционный директор

Ты не создаёшь воронки — это 6–12 месяцев обучения. Кирилл потратил полгода только на то, чтобы научиться их собирать, и ещё полгода чтобы понять как они работают на практике.

Твоя задача — контролировать операционный процесс и освобождать Кирилла от рутины.

Как выглядит работа операционного директора

Кирилл ставит цель → Ты находишь решение → Приходишь с готовым ответом
         ↓
Кирилл: "ок" или "передоговаривайся"
         ↓
Ты реализуешь → Берёшь отчёт → Докладываешь Кириллу с выводами
         ↓
Если выхлоп мал → сам придумываешь как усилить
🔍
Найти людей
Рассыльщики, исполнители. Ты ищешь, объясняешь условия, приходишь с готовым: "Вот Семён, завтра выходит".
📊
Контролировать
Ежедневные отчёты с команды. Анализировать выхлоп. Если мало — находить решение, не ждать когда Кирилл заметит.
📢
Докладывать
Кирилл не может заниматься операционкой — он в онлайн-школе и на проектах. Ты его глаза и руки.
"Я говорю: это плохо, надо усилить. Задача: усилить. КАК — неважно. Важно чтобы было усилено." — Кирилл

Раздел 03
Философия 0.8 / 1.0 / 1.2 — самое важное
📉
0.8 — Слабое звено
Задачи не выполняет. Дедлайны переносит. Нет инициативы. Надо постоянно контролировать. "Не смог сделать 30 рассылок, только 25 — заблокировали".

На взрослой работе нет слова "не сделал".
➡️
1.0 — Исполнитель
Делает задачи чётко — не больше и не меньше. Если неправильно поставить задачу — сделает неправильно, но сделает. 100% — это плохой результат: рост = ноль.
🚀
1.2 — Проактивный
Делает на 20% больше чем задали. Задача: 20 рассылок → сделал 24. Нет задачи → сам видит что делать. Один такой человек тянет весь проект до 1.2.

Математика команды

3 человека по 0.8 0.8 × 0.8 × 0.8 = 51%
2 единички + 1 человек 0.8 1.0 × 1.0 × 0.8 = 80%
3 единички 1.0 × 1.0 × 1.0 = 100%
2 единички + 1 человек 1.2 1.0 × 1.0 × 1.2 = 120%
Ты 1.2 + отдел 1.2 × 3 1.2 × 1.2 × 1.2 × 1.2 = 207%
"Если мы перевыполняем план на 160% — это просто команда чемпионов. Ничто не мешает нам стать самым топовым агентством по созданию автоворонок." — Кирилл

Как стать 1.2 конкретно

  • Задача: 20 рассылок → ты делаешь 24
  • Задача: найти рассыльщика → ты нашёл + объяснил условия + он уже вышел + взял первый отчёт
  • Нет задачи → сам ищешь что делать (рассылки, поиск людей, отчёты)
  • Семён не справляется → ты уже думаешь о втором человеке и предлагаешь Кириллу
  • Каждый вечер — отчёт Кириллу без напоминания
  • Каждое утро — план на день без запроса

Два пути одновременно:

  • Искать рассыльщиков — найти, объяснить условия, показать Кириллу, утвердить, запустить
  • Пока ищешь — сам делать рассылки — не ждать когда найдёшь

  • Рабочий план на неделю — составить и отправить Кириллу
  • ТЗ по Юле — посмотреть что скинул Кирилл, дать фидбэк
  • Объявление с ассистентом — собрать сегодня
  • Изучать материалы по воронкам через Claude — понимать систему, не создавать
